NEAR-PURE HTML ARCHITECTURE

About Kuina Tech

01 / SIMPLE WEB

ほぼ純HTMLの軽快な構成 Near-Pure HTML Simplicity

重いフロントエンドフレームワークを使わず、HTML・CSS・素のJavaScriptを中心に構成。ブラウザですぐに開いて軽快に遊べます。 Built on clean HTML, CSS, and vanilla JavaScript with zero frontend framework bloat for fast loading and responsive gameplay.

02 / GAME CENTER

games.json でゲームを簡単追加 Easy Game Center Expansion

src/data/games.json に新しいゲームの情報を足してビルドするだけで、Game Center にカードとリンクが自動生成されます。 Add a game entry in src/data/games.json and rebuild to automatically publish its card and play links inside Game Center.

03 / BUILD TOOL

1ページ静的ビルド出力 Single-Page Static Build

build.ps1（または npm run build）でHTMLパーツとCSS/JSを結合し、dist/ にそのままデプロイ可能な静的サイトを出力します。 Run build.ps1 or npm run build to assemble partials, hashed assets, and playable game bundles into dist/.
